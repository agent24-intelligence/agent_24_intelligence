## 준비 vs 커밋 경계 (From Scratch 룰)
"8/1 14:00 이후 커밋만 인정, GitHub commit history 제출 필수"가 룰이지만, **커밋만 안 하면 사전 준비는 자유**다.

14:00 이전에 해도 되는 것
- 시스템 프롬프트 문구를 문서에 통째로 써두기 — 이후엔 복붙만
- API 테스트 호출(Postman/curl) — 프로젝트 코드가 아니라 API 학습이라 무관
- 점수 계산 가중치·신호 목록을 스프레드시트로 확정
- 슬라이드, 와이어프레임, 발표 대본 (코드가 아니므로 규칙 대상 아님)
- 로컬에 프로젝트 스캐폴딩(폴더 구조, package.json 등) 파일로 준비 — 단, GitHub에 올리는 건 14:00 이후

주의: 커밋 타임스탬프가 14:00 이전이면 그 자체가 위반 증거가 된다. 로컬 준비는 자유이나, 원격 저장소에 올리는 순간부터 룰이 적용된다.
